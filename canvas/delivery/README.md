## 一、项目背景

QADB 是开源跨平台 ADB 桌面调试工具（基于 Compose Multiplatform，覆盖 Windows / macOS / Linux 桌面三端）。本次交付为其 **AI Agent 页面** 的高保真 HTML 原型，聚焦「让 Agent 的工作透明可见，让设备的状态一目了然」——将 AI 对话流、实时设备画面镜像、视觉观察模式、工具调用历史、Token 消耗计量整合为单页三栏工作台，面向 Android 开发者/测试人员等专业用户。

## 二、设计哲学

> **「让 Agent 的工作透明可见，让设备的状态一目了然。」**

这是一个工具，不是一个聊天玩具。所有新增信息（思考链、工具调用、Token、观察状态）都服务于「专业用户信任并掌控这个 Agent」这一目标：克制的视觉让数据本身说话，思考链/工具调用默认折叠可展开，避免淹没主对话流。

## 三、设计系统

- **方案名**：QADB Workbench（Linear-Class）
- **参考系**：Linear（工作台基底）· Warp（AI 过程可视化）· Raycast（输入/导航范式）
- **主题**：Light / Dark 双主题（顶栏右上角太阳/月亮按钮一键切换）
- **双色语义**：🔵 QADB 蓝 #2196F3 = 设备 / 品牌 / 主操作；🟣 AI 紫 = Agent 活动遥测（思考链、工具调用、Token、观察模式）
- **骨架**：顶部 44px 通栏 + 左导航 220px / 中央对话区（弹性，文本列 ≤720px）/ 右设备面板 400px（可折叠）

## 五、查看方式

1. **直接打开原型**：双击 `qadb-aiagent.html`，用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可，无需安装依赖、无需启动服务。
2. **建议分辨率**：1440×900（最佳）；1280×800 可用；<1080 自动折叠为紧凑模式。
3. **交互演示点**：
   - 顶栏右上角 🌙/☀ 按钮 → Light / Dark 主题一键切换
   - 对话流中「思考过程 / am start / input text」卡片 → 点击卡头展开/折叠完整命令
   - 右侧「视觉观察模式」大开关 → 开启/暂停观察（状态点蓝色呼吸 = AI 正在看屏幕）
   - 右侧「收起面板」按钮 → 收起设备面板，右下角 ‹ 重新展开
   - 底部输入区小开关 → 快速切换视觉观察模式

## 六、核心改进（对比原页面）

1. **视觉观察模式升为一级信息**：从角落小标签升级为右侧面板核心卡片（大开关 + 状态说明「AI 正在看你的屏幕」+ 观察频率 + Page id/changed 徽标），并支持底部输入区快捷开关。
2. **工具调用透明化**：对话流内联 `am start / input text / input tap` 工具卡，含状态点（已执行/待确认/失败）、时间戳、可展开完整命令。
3. **思考链可见**：Agent 推理过程以可折叠卡片呈现，默认折叠成一行，避免黑盒感且不淹没对话。
4. **任务进度可视化**：新增 Activity 步骤时间线（打开微信 → 搜索联系人 → 输入内容 → 点击发送），状态一目了然。
5. **Token 消耗计量条**：从一行文字升级为小型计量条（45,449/128,000）+ 压缩次数徽标。
6. **敏感操作内联确认**：发送消息等风险操作前出现危险确认卡（确认发送/取消），工具卡联动「待确认」态。
7. **输入区钉住底部**：修复原悬浮遮挡问题，对话流底部预留安全间距，滚动到底不被遮挡。
8. **双主题令牌化**：整体从基础 Material 风格升级为 QADB Workbench 双主题设计系统，Light/Dark 一键切换，状态语义（成功绿/失败红/进行中蓝）明确统一。
